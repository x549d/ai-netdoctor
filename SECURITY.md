# Security policy

Security fixes target the latest stable release. Please reproduce on that release if practical.

Use [GitHub private vulnerability reporting](https://github.com/x549d/ai-netdoctor/security/advisories/new) for potential vulnerabilities, including credential disclosure, TLS verification bypass, or unintended requests. Include the affected version, a minimal reproduction with placeholders, and the expected and actual behavior. Use public issues for ordinary connectivity problems.

Remove API keys, tokens, proxy usernames and passwords, and private network details from examples and attachments. The maintainer coordinates verification, fixes, and disclosure in the private advisory.

## 中文

安全修复面向最新稳定版。发现凭证泄露、TLS 校验绕过或意外请求等漏洞时，请通过 [GitHub 私密漏洞报告](https://github.com/x549d/ai-netdoctor/security/advisories/new) 提交。请附受影响版本、使用占位符的最小复现以及预期与实际结果，并删除密钥、代理凭证和私有网络信息。普通连接问题请走公开 Issue。
